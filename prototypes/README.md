# Prototypes

Files here are exploratory and are not imported, bundled, deployed, or supported as production Polycast surfaces. Each prototype names its canonical production source where one exists. Promotion requires an owner, automated checks, documented installation, and inclusion in the root release gate.

- `srs-sandbox.html` visualizes study behavior; `contracts/srs-v1.json` and its generated implementations are authoritative.
- `vlc/` is an optional local Lua experiment for sidecar subtitles. It opens the deployed web dictionary and is not part of release packaging.
